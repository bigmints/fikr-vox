# Security policy

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/bigmints/Fikr-Vox/security/advisories/new). If private reporting is unavailable, email `support@fikr.app` with the subject **Fikr Vox security report**.

Include the affected version or commit, your operating system, steps to reproduce the issue, and its impact. Redact credentials and use synthetic or sanitized media. Please keep vulnerability details private while the maintainers investigate.
